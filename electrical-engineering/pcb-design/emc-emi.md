# EMC/EMI

Electromagnetic Compatibility (EMC) and Electromagnetic Interference (EMI) are key contributors to a lot of the mysterious failures when working with electronics. The way to get around it is to understand the origins of EMI and EMC in electronics and then learning to build towards.



There's a couple of ways to set up the EMI simulations in KiCAD, OpenEMS is an open source tool that can be used to simulate the EMI interactions in the design.
